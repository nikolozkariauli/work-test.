Box Layout — ეს არის ვებ ბრაუზერის მიერ გამოყენებული მოდელი, რომელიც განსაზღვრავს თუ როგორ უნდა განთავსდეს და გამოისახოს თითოეული ელემენტი გვერდზე. იგი ეფუძნება CSS-ის "box model"-ს, სადაც ყველა ელემენტი განიხილება როგორც მართკუთხა ყუთი. Box Layout შედგება 4 ძირითადი შრისგან: 1) Content (შიგთავსი) - ეს არის ის რეალური ინფორმაცია, ტექსტი, სურათი ან სხვა ელემენტი, რომელიც მომხმარებელს უნდა გამოუჩნდეს. - ზომა განისაზღვრება width და height თვისებებით. 2) Padding (შიგთავსის შიდა დაშორება) - სივრცე content-სა და border-ს შორის. - გამოიყენება იმისთვის, რომ ტექსტი ან სურათი არ მიეკრას უშუალოდ საზღვარს, ქმნის "სუნთქვის" სივრცეს ელემენტის შიგნით. 3) Border (საზღვარი) - ხაზოვანი ჩარჩო, რომელიც გარს აკრავს padding-ს და content-ს. - შეიძლება ჰქონდეს ფერი, სისქე და სტილი (მაგ: solid, dashed). - Border ხშირად გამოიყენება ელემენტის ვიზუალური გამოყოფისთვის. 4) Margin (გარე დაშორება) - სივრცე ელემენტის საზღვარსა და სხვა ელემენტებს შორის. - margin უზრუნველყოფს ელემენტებს შორის დაშორებას, რათა გვერდზე განლაგება იყოს ჰარმონიული და არ გადაიკვეთოს.
